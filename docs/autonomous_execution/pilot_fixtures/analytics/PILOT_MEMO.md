# Pilot Memo — Synthetic Quarterly Revenue Growth (AES Phase 4 Analytics Pilot)

> **This is fictional pilot data, not a real business claim.** Every
> figure below comes from `raw_sales.csv`, a 16-row invented fixture
> (fictional "Widget A/B/C" products, fictional "North/South" regions,
> fictional order IDs). Nothing here describes any real company,
> product, customer, or transaction. This memo exists only to
> demonstrate the `[Analytics]` memo format under AES tracking
> (`docs/pilots/AES_ANALYTICS_PILOT.md`), following the shape described
> in `ChatGPT/[Analytics]/Knowledge/ANALYTICAL_MEMO_STRUCTURE.md`.

## Finding

In the synthetic pilot fixture, completed-order revenue grew from a
fictional **$950** in Q1 to a fictional **$1,180** in Q2 — a
**+24.21%** quarter-over-quarter increase.

## Method

- Source: `raw_sales.csv` (RAW), 16 synthetic order-line rows, grain =
  one row per `order_id`.
- Pipeline: `scripts/pilot_analytics_build_mart.py` builds STAGE
  (`stage_sales.csv`, same grain as RAW, adds `revenue_usd` per row) then
  MART (`mart_sales_by_quarter.csv` / `.json`, grain = quarter x region x
  product).
- Formula: `revenue_usd = units * unit_price_usd`, computed only for
  `status == "completed"` rows (`metric_rules` in `DATA_CONTRACT.md`).
  Cancelled orders (2 of 16 rows) are excluded from all revenue totals.
- Growth formula: `(Q2_total - Q1_total) / Q1_total * 100`.

## Numbers

## Reconciliation status

RAW completed-order revenue (contract-defined ground truth) == STAGE
completed-order revenue == MART total revenue == **2,130.00** (synthetic
USD), across both quarters combined. All 5 reconciliation checks in
`reconciliation_report.json` are `true`; `overall_pass: true`.

This number was **not always correct**: the first build of this
pipeline had a defect (`def-001`, classification `contract` /
`data_or_mapping_fix` — MART aggregation omitted the
`status == "completed"` filter, so cancelled-order revenue leaked into
the MART total). That defect made reconciliation FAIL (MART total
2,440.00 vs. contract-expected 2,130.00; reported growth 19.82% instead
of the correct 24.21%). It was found, registered, and fixed before this
memo's number was drawn — see
`docs/pilots/AES_ANALYTICS_PILOT_RESULTS.md` for the full before/after
command output, and
`docs/autonomous_execution/examples/pilot_evidence/analytics_pilot.json`
for the structured defect/iteration record.

## Confidence and limitations

- Confidence: high, **for this synthetic fixture only** — the
  reconciliation is exact (integer/decimal arithmetic on 16 rows, no
  sampling, no estimation).
- Limitations:
  - Fixture is intentionally tiny (16 rows, 2 quarters, 2 regions, 3
    products); it is not statistically representative of anything and
    is not meant to be.
  - No seasonality, outlier, or trend analysis was attempted — a single
    two-point QoQ comparison only.
  - This is a synthetic dataset invented for pilot purposes. It carries
    **no evidentiary weight about any real business**, past, present,
    or hypothetical.
