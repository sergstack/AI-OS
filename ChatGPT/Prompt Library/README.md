# Root Prompt Library Role

State: `legacy_reference` / `special_non_registry_surface`.

This folder preserves bounded standalone prompt artifacts and their lineage. It
is not an active Prompt Registry and does not own reusable prompt lifecycle,
eval status, acceptance, or promotion.

The canonical reusable asset owner is:

`ChatGPT/[LLM]/Knowledge/PROMPT_REGISTRY.md`

Before reusing or materially revising a prompt from this folder, register the
asset or candidate revision under the `[LLM]` lifecycle. Do not infer an eval
pass, owner acceptance, or active status from file presence here.
