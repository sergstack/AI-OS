# Knowledge Bundles — [Thinkers OS]

## Purpose

This folder contains the only standard manual upload artifacts for ChatGPT Project `[Thinkers OS]`.

Granular files in `ChatGPT/[Thinkers OS]/Knowledge/` remain repository source of truth. Do not delete them, replace them with bundles, or upload both layers together except controlled debugging.

## Upload policy

- Paste `ChatGPT/[Thinkers OS]/PROJECT_INSTRUCTIONS.md` into Project Instructions.
- Upload only bundle files listed in `UPLOAD_LIST.md` into Project Sources / Knowledge.
- External Project creation and upload remain manual owner actions.
- Do not upload raw or normalized books, OCR dumps, source manifests, execution logs, local paths, secrets, blocked/rejected artifacts, embeddings, vector databases, or archives.
