# Memo Generation Workflow

## Pipeline

```text
curated context
→ draft
→ judge
→ revise
→ final memo
→ QA
```

## Inputs

- verified numbers;
- evidence cards;
- required sections;
- audience;
- tone;
- constraints.

## Required sections

1. Executive summary.
2. Key facts.
3. Analysis.
4. Risks.
5. Recommendations.
6. Limitations.
7. Evidence appendix.

## Judge criteria

- unsupported claims;
- missing evidence;
- overconfident recommendations;
- unclear numbers;
- weak structure;
- wrong audience.
